# 💰 7 Days of Code — App de Controle Financeiro
Repositório oficial do desafio **7 Days of Code**[span_1](start_span)[span_1](end_span). 
Ao longo de 7 dias, o objetivo é construir, na prática, utilizando Inteligência Artificial e a ferramenta **Lovable**[span_2](start_span)[span_2](end_span), um **App de Controle Financeiro** completo voltado para pequenos negócios e autônomos[span_3](start_span)[span_3](end_span). No final, o projeto estará publicado e pronto para o portfólio[span_4](start_span)[span_4](end_span).
---
## ⚙️ Como funciona
Cada dia do desafio possui sua própria branch contendo[span_5](start_span)[span_5](end_span):
* **Conceito do dia** — A explicação do que você vai aprender[span_6](start_span)[span_6](end_span).
* **Desafio do dia** — O enunciado e o prompt sugerido para usar no Lovable[span_7](start_span)[span_7](end_span).
* **Saída esperada** — O resultado visual e funcional esperado ao final do dia[span_8](start_span)[span_8](end_span).
* **Exercício opcional** — Um extra para ir além (quando houver)[span_9](start_span)[span_9](end_span).
* **Dica** — Um direcionamento extra para ajudar no desafio[span_10](start_span)[span_10](end_span).
